# Nokori のお知らせページ

献立アプリ **Nokori** の、サポートとプライバシーポリシーのページです。

- サポート: https://ryoto-6174.github.io/nokori-site/
- プライバシーポリシー: https://ryoto-6174.github.io/nokori-site/privacy.html

アプリ本体のコードは、このリポジトリには入っていません。

## 直すとき

`index.html` と `privacy.html` を直して push すると、数分で反映されます。
見た目の指定は各ファイルの中に入っているので、**1ファイルだけで完結**します。
